How the work runs

Same four steps,
whichever job.

A website, a shoot and a control system are different jobs with the same shape. Agree the scope, write it down, build it, hand it over properly.

01

Scope

We work out what you actually need, what it costs and when it lands. No discovery theatre, no surprise line items.

02

Spec

Wireframes, a shot list or a functional description — whatever the job calls for, written down and agreed before work starts.

03

Build

Code, shoot or commission. You see progress while it happens, on a staging link or a proof gallery, not in one reveal at the end.

04

Handover

Deployed, delivered or signed off, with documentation and support that doesn't expire the week after launch.
